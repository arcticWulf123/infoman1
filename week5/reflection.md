SELECT statements are safe to run because they only retrieve data, unlike DDL where it affects the structure of the database itself and can heavily influence how the database works. It's main function is to gather data from a table. You can narrow your search much further by chaining it with FROM and WHERE for more precise results. I introduced a missing quote syntax in my program, where instead of using this command: SELECT name FROM Pet WHERE species = 'Cat', I did this SELECT name FROM Pet WHERE species = 'Cat. When I typed in the incorrect command, it went to the next line and said " '> ", from what I have learned, Mysql thinks you are still typing a string, so it waits for you to close it with a quote and semicolon. To get out of it you need to use ctrl + c, this commands cancels the unfinished statement and returns you to the normal prompt.
