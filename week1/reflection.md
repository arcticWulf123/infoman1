# MySQL prevents Data Inconsistency, when different people access the database and needs to configure or add new data, MySQL reflects or applies the change to all users, MySQL also enforces integrity, meaning the system can reject contradictory or invalid changes. Another superior aspect of having a database over file management is that it has controlled redundancy, this basically means that you no longer have to manually update the change you made in an entity's attribute as doing so is very time-inefficient and slow.
# I personally think that Backup & Recovery is the most crucial DBA responsibility as mistakes can definitely happen in a real-world setting. Accidental deletion, unintended entity attribute edits or any other mistakes when it comes to handling data can be mitigated by simply having a backup of student records another reason is that backups can prevent permanent data loss rather than having no way to recover data and the deleted data is permanantly gone, simply trying to recreate that data can be both time-consuming and costly.
